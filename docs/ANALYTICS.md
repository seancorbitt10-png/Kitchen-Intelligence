# Analytics

Track acquisition, signup, onboarding completion, first pantry addition, first scan, first meal generation, meal view, save, cook, repeat generation, repeat pantry usage, pricing view, checkout start, subscription start/cancel, shopping-list creation, product search, product click, and provider failures.

Analytics must be user-scoped where appropriate, avoid unnecessary private content, and remain removable through account deletion. AI usage is tracked separately with operation, provider, model, token fields, estimated cost, success, and timestamp.
