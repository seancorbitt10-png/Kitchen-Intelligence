# Implementation Plan

## Completed foundation

Authentication, schema, user-scoped access, onboarding, pantry persistence, structured AI boundaries, meal generation, shopping lists, usage rows, analytics hooks, privacy deletion, responsive UI, and protected admin summaries are implemented.

## Next blockers

Connect and test a real billing provider, complete subscription lifecycle webhooks, add verified retailer/product adapters, expand recommendation scoring beyond prompt context, add pantry deduplication and inline editing, and build integration tests against an isolated database.

## Expansion

Weekly meal plans, leftovers, serving scaling, purchase history, product optimization, household collaboration, receipt OCR, and advanced predictive replenishment should follow only after the core scan-to-meal loop is reliable and measurable.
